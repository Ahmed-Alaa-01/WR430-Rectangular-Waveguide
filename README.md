# WR430-Rectangular-Waveguide
his repository contains the electromagnetic simulation of a WR-430 rectangular waveguide, including the simulation files, generated results, and supporting images.
The project focuses on analyzing the electromagnetic behavior and propagation characteristics of the WR-430 waveguide using CST Studio Suite.
